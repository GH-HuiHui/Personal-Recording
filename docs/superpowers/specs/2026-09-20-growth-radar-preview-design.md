# 成长雷达初步预览设计

## 目标

交付一个可离线打开的单页 HTML 原型，用于预览 GrowthRadar v1 的核心信息层级和记录节奏；它不是 SwiftUI 或 SwiftData 的正式实现。

## 范围

- 固定 iPhone 尺寸的深色设备预览框，适配桌面浏览器查看。
- 三个 Tab：今天、历史、设置。
- 今天页默认展示“近 7 日”雷达图、6 个默认方向和每张卡片的今日/近 7 日次数。
- 支持切换“近 7 日 / 本阶段”图表指标。
- `+1` 更新对应卡片的次数和雷达值，并显示约 3 秒的可撤销提示。
- 历史页仅展示模拟的阶段列表与阶段摘要；设置页仅展示当前阶段和方向编辑入口。

## 交互和数据

页面使用内存中的模拟数据。点击 `+1` 同时增加今日与近 7 日次数；近 7 日活跃天数上限为 7。本阶段视图显示预置活跃率。撤销只恢复最近一次点击造成的模拟变更。刷新页面后恢复初始演示数据。

## 视觉规范

遵循原设计文档：系统深色背景、低饱和蓝色作为唯一操作强调色、细网格雷达图、SF Symbol 风格图标、无积分或连续打卡元素。首页视觉焦点依次为：阶段与指标切换、雷达图、方向卡片的 `+1`。

## 验收

双击 HTML 后可在现代浏览器打开；Tab、指标切换、`+1` 与撤销均可操作；雷达图随 `+1` 变化；不依赖网络或构建工具。
