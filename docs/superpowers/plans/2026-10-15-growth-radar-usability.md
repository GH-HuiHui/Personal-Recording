# 成长雷达使用问题修复

目标：方向可以自定义顺序和图标，图表可以设置，备份可保存，归档阶段可清晰核对投入。

架构：继续使用 Framework7、原生 JS 和 IndexedDB。排序只更新当前阶段的 sortOrder；可选 chartPreferences 保存在阶段对象并随加密备份往返。文件保存和阶段统计分别独立成模块，不迁移现有数据库。

1. 方向与图表：增加上下移动、图标选择，提供雷达/条形图、四种颜色、数值开关；排序事务校验完整且不重复，归档数据只读。
2. 备份：加密后通过新的用户点击打开系统保存或文件分享；提供绕过 Framework7 路由的直接下载。取消保留文件；数据更新要求重新生成备份。保留旧版备份兼容性。
3. 阶段回顾：展示日期、行动总数、活跃日、阶段时长、方向次数条形对比和每日明细；计入停用方向，活跃率以结束日固定；明细每次加载 50 行。
4. 验收：完整 Vitest、生产构建、依赖检查；手机和桌面交互验证排序、重载持久化、图表配置、下载后解密恢复、阶段归档与零记录状态。推送 master 后确认 GitHub Pages 工作流成功。

限制：桌面自动化验证下载文件及分享接口分支；iPhone 原生“存储到文件”需真机确认。


## 方向排序交互修订

以拖动手柄替代上下箭头：拖动中其他项自动让位，靠近弹窗边缘持续自动滚动，松手仅保存一次。直接选择“第 N 位”也可一次跨过多个方向并自动保存。普通列表滑动与名称编辑保留；取消拖动及保存失败恢复原顺序，持久化仍使用原有完整排列事务。
