# 成长雷达月度 AI 分析 SOP

这是一套手动流程。应用只在你的设备上读取记录、生成图表和 CSV；不会自动联系 AI 服务。CSV 和图片包含个人行动信息，是否交给外部 AI 由你决定。不要上传加密备份文件，也不要把导出文件提交到 Git 仓库。

## 1. 导出并核对

1. 打开「历史 → 月度趋势」，选择要分析的月份。
2. 核对页面显示的总次数、活跃天数与月份；点击「导出 CSV」。如需可视化附件，再点击「导出趋势图」。在 iPhone 上按 Safari 的文件保存界面确认文件确实保存成功。
3. 打开 CSV，确认首行字段是 `日期,阶段序号,阶段,方向序号,方向,次数`，日期属于所选月份，次数与页面总数一致。CSV 对阶段与方向的每个有效日期都包含零次行；当月仅包含今天及以前。阶段序号、方向序号用于区分重名对象。
4. 如不愿披露阶段或方向名称，可在本机复制 CSV 后替换为代号，再交给 AI；请保留日期、序号和次数，否则趋势会失真。不要修改原始备份。

## 2. 手动分析

在你信任的 AI 工具中新建对话，主动附上核对过的 CSV。图片是可选的辅助材料；数字结论必须以 CSV 为准。可复制以下提示词，将月份替换为实际月份：

```text
请仅依据我附上的成长雷达 CSV，分析 {YYYY-MM} 的行动记录，并写一份中文月度报告。

字段：日期、阶段序号、阶段、方向序号、方向、次数。每行是某个本地自然日、阶段、方向的记录次数；零次行表示该日没有该方向的记录。记录次数不是投入时长、效果或能力评分。阶段序号和方向序号用于区分重名对象。

报告按以下顺序输出：
1. 数据范围与质量：实际覆盖日期、总记录次数、至少记录一次的活跃天数、是否存在空缺或无法解释的字段。
2. 事实：逐周次数变化、各方向次数、连续活跃或间断日期；如月内发生阶段切换，分别说明。每项结论给出具体日期或数字依据。
3. 解释与建议：只提出最多三条可执行建议，明确它们是推断，不把相关性写成因果，也不把记录次数当作成果。
4. 局限：缺少时长、质量、目标完成度和主观感受时，明确哪些判断不能作出。

若数据不足，请直接说明不足，不要补造记录、成长评分、心理状态或失败原因。若图片与 CSV 不一致，以 CSV 为准并指出差异。
```

## 3. 人工复核与保存

- 对照 CSV 复核报告中的总数、活跃天数、阶段切换和关键日期；把未经数据支持的推断删掉或改成问题。
- 报告由你自行保存。应用没有报告存储或云同步；下次分析需重新导出。
- CSV/PNG 是未加密文件，完成分析后按你的保留习惯妥善存放或删除。加密 `.growthradar` 备份仍用于数据恢复，不能由 CSV 替代。
